# Courtyard Material Studio

An interactive courtyard materials planner with a rotatable 3D model and editable plan.

- Drag materials onto walls, paving, gravel and other surfaces.
- Select an area to centre and highlight it.
- Review unfinished surfaces, mark items not needed, and restore removed items.
- Hover over surfaces and features to see product names.
- Save an editable HTML backup with the **Save planner** button.

The published starting choices come from the saved planner dated 26 November 2026. Changes are stored locally in each browser; they are not automatically shared with other visitors or written back to GitHub. Use Save planner to keep a portable backup.

## Hosting

This is a self-contained static site. `index.html` embeds the application, reference images and Three.js runtime. GitHub Pages can publish the repository root from the main branch. `.nojekyll` disables Jekyll processing.

The model is a design/material placement study based on the supplied drawings.
